# Decision Log

> **Rules:**
> - Every agent session must append new decisions here
> - Do not edit existing entries — this is an immutable record
> - Only document decisions that future agents need to know about and respect
> - If a decision is later reversed, append a new entry — do not delete the original

---

## Format

```markdown
### [DECISION TITLE]
- **Date:** [when the decision was made]
- **Context:** [what problem or question prompted the decision]
- **Decision:** [exactly what was decided]
- **Reason:** [why this was chosen over alternatives]
- **Impact:** [what this affects — files, patterns, future tasks]
- **Do not:** [what future agents must not do that would conflict with this decision]
```
